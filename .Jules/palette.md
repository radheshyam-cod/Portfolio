## 2025-02-14 - Dynamic Context for Mapped Icon Links
**Learning:** Icon-only links within mapped collections (like grids or lists) cause a severely degraded experience for screen reader users when they lack context-specific text. When screen readers announce multiple identical "GitHub" or "Live Demo" links on a page, users cannot determine which project each link belongs to without exploring surrounding DOM elements.
**Action:** Always enforce dynamic, context-specific strings incorporating the item's unique identifier or title (e.g., `aria-label={"View source code for " + project.title}`) on icon-only links within mapped collections. Additionally, mirroring this string to the `title` attribute provides a helpful tooltip for sighted mouse users hovering over the small touch targets.
